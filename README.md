# くりかえしリマインダー

アプリで「完了」を押すまで、アラームを停止するたびに3分後に再通知する、iPhone向けのリマインダーアプリです。

## 主な機能

- リマインダーの作成・編集・削除、有効／無効の切り替え
- 通知時刻と曜日ごとの繰り返し設定
- AlarmKitによるアラームと、停止後3分での再通知
- 完了履歴、月ごとのカレンダー・完了率・完了数
- ピンク・ブルー・グリーン・イエローのテーマとアイコン

iOS 26以降に対応。アカウント登録は不要で、データはiPhone内に保存します。

## 開発

Swift / SwiftUI / AlarmKitを使用しています。

Xcodeで `SimpleReminder.xcodeproj` を開き、`SimpleReminder` スキームを選んでビルドしてください。実機で動かす場合は、自分の開発チームとBundle Identifierを設定します。
